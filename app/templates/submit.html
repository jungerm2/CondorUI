The following variables are automatically set by the Web UI and can be used in submit descriptions:

Standard HTCondor Variables

Variable Description
$(ClusterId)The cluster ID assigned to this job by HTCondor
$(ProcId)The proc ID for each process (0, 1, 2, ...)
$(Owner)The user who submitted the job
$(QDate)The date and time the job entered the queue (Unix timestamp)

Web UI Custom Variables

Variable Description
$(LogsDir)Per-job directory for log, stdout, and stderr files
$(OutputsDir)Per-job directory for output files transferred back from the job

Example: output = $(OutputsDir)/$(ClusterId).out writes output to a per-job directory. See the HTCondor Manual for more submit file options.
