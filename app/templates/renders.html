These variables are set by the Web UI and can be used in the fields above.

Standard HTCondor Variables

VariableDescription
$(ClusterId)The cluster ID assigned to this job by HTCondor
$(ProcId)The proc ID for each process (0, 1, 2, ...)
$(Owner)The user who submitted the job
$(QDate)When the job entered the queue (Unix timestamp)

Web UI Variables

VariableDescription
$(LogsDir)Per-job directory for log, stdout, and stderr files
$(OutputsDir)Per-job directory for output files transferred back from the job
$(ResearchDrive)ResearchDrive base path, from the Output card — usable in output remaps
$(SceneName)Blend filename without extension, per cluster (e.g. classroom)

$INT(ClusterId,%08d) formats a variable (here: zero-padded cluster id). See the HTCondor Manual for all submit-file options.
